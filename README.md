# ATM Simulator

## Description

A simple ATM simulator built using Python.
The project allows users to check their balance, deposit money,
withdraw money, and exit the program.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Prevent withdrawals when the balance is insufficient
- Handle invalid menu choices
- Exit the program

## Concepts Practiced

- Variables
- Input and output
- If / elif / else
- While loops
- Continue
- Break
- Basic arithmetic
- User input validation

## How to Run

1. Make sure Python is installed.
2. Open the project folder.
3. Run `atm.py`.
